How Dijkstra works

  1. Set dist[source]=0, all others ∞; prev[v]=none; push (0, source) into a min-heap.
  2. Pop the unvisited node u with the smallest tentative distance; mark it visited.
  3. For each usable edge (u,v,w) with w ≥ 0: if dist[u]+w < dist[v], set dist[v]=dist[u]+w, prev[v]=u and push v.
  4. Stop when the destination is popped or the heap is empty (unreachable).
  5. Rebuild the path by following prev from destination to source.
DIJKSTRA(G, s, t):
  for v in V: dist[v]=∞; prev[v]=nil
  dist[s]=0; H=minheap{(0,s)}
  while H not empty:
    (d,u)=EXTRACT-MIN(H)
    if u visited: continue
    mark u visited
    if u==t: break
    for (v,w) in Adj[u], w≥0, edge not blocked:
      if d+w < dist[v]: dist[v]=d+w; prev[v]=u; INSERT(H,(dist[v],v))
  return path via prev

Complexity: with an adjacency list and a binary min-heap, O((V+E) log V) time (lazy deletion gives at most E heap entries, so log E = O(log V)); space O(V+E). Correctness requires non-negative weights, so invalid or negative edges are skipped and reported. Alternatives are found by blocking each edge of the best path in turn and re-running Dijkstra, which gives simple detour routes, not a full k-shortest-paths guarantee.
